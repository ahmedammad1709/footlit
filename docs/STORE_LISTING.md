# Store listing copy (Chrome Web Store, Edge Add-ons, Firefox AMO)

## Name
Footlit

## Summary (max 132 characters)
Themed full-screen celebrations for GitHub: merged PRs, green checks, releases and deploys. Six hand-built themes. All local.

## Category
Developer Tools

## Single purpose
Footlit plays a themed animation on github.com when you complete a GitHub milestone (such as merging a pull request or publishing a release).

## Description

GitHub, with stage lighting.

Merge a pull request, watch the checks go green, publish a release, put a site live: Footlit makes GitHub answer with a proper entrance. Pick a theme, and every moment gets its own full-screen show.

WHAT IT REACTS TO
- Repositories: created, deleted, forked
- Pull requests: opened, merged, closed
- Checks and deploys: checks passed, checks failed, site or deploy live
- Releases and issues: release published, issue closed

SIX THEMES, EACH A COMPLETE PRODUCTION
- Marquee: footlights, a hanging bill, a ticket stub and a lot of paper confetti
- Terminal: a shell, an ASCII merge graph and an exit code
- Mission Control: a countdown, a GO/NO-GO poll and a trajectory (and an abort when a check fails)
- Pixel Arcade: "STAGE CLEAR!" and "GAME OVER" in sixteen colours
- Web Crawler: webs spin out from the corners, spiders crawl, the web tears when the build breaks
- Quiet: one small toast in the corner, for the office

Every theme has a celebration, a farewell and an alarm version. Give any event its own theme, preview everything live in settings, rehearse any show on your open GitHub tab, and switch it all off for an hour with Quiet mode.

MADE TO BE POLITE
- Never blocks the page or captures clicks; press Esc to skip a show
- Only reacts to things that happen while you watch: opening an already-merged pull request plays nothing
- Respects your system's reduced-motion setting
- Switch off any event you do not want

PRIVATE BY DESIGN
Footlit runs only on github.com, makes no network requests, and keeps its settings in your browser. No analytics, no tracking, no accounts.

## Permission justifications (for the review form)

- **Host permission https://github.com/\***: The content script runs on github.com to detect that you completed a milestone (from the page address, title and status badges) and to draw the animation over the page. The popup also needs it to message the open GitHub tab for the Rehearse buttons. The extension does nothing on any other site.
- **storage**: Saves the user's settings (theme, enabled events, preferences) and a short local activity log shown in the settings page.
- **Remote code**: None. All code and fonts are bundled in the package.
- **Data usage**: No user data is collected, transmitted or sold. See the privacy policy.

## Notes for reviewers

To see it work you need a GitHub account. Install, open a GitHub tab (reload it once), click the Footlit toolbar icon, and press **Rehearse** next to any event to play it on that tab immediately. To see a real trigger: open a pull request in a test repository and merge it while the tab is open (or create a repository, open the Actions page of a running workflow, etc.). The **Settings** page has a live preview of every theme and a Recent activity list.
