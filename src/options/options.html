Welcome

Three steps and you're done

  1. Pick a theme below. Click a card to preview it.
  2. Rehearse an event in the Events section to see it play.
  3. Open GitHub and make something happen. Footlit takes it from there.

    Recent activity

      Not working?

      Rehearse does nothing on GitHub

      Reload the GitHub tab once after installing or updating Footlit. The popup tells you when a tab is out of date and gives you a Reload button.

      A real event didn't play

      Check Recent activity above. If the event is listed as "not shown", the reason is next to it (Footlit is off, that event is off, or quiet mode). If it isn't listed at all, the page wasn't recognised. Turn on debug logging by running this in the GitHub tab's console, repeat the action, and look for lines starting with [footlit]:

      localStorage.setItem('footlit:debug','1')

      I want it quieter

      Use the Quiet theme for a small corner toast, switch off events you don't care about, set the length to Brief, or use Quiet mode to pause everything for an hour.

      What does Footlit read?

      It runs only on github.com, watches the page you have open to notice things like a merge or a check finishing, and plays an animation. Settings and the activity log live in your browser. Nothing is sent to any server.

      Reset

      Put every setting back to how it was when you installed Footlit.
